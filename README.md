# StatMind: AI-Assisted Data Analysis Dashboard

StatMind is an AI-assisted interactive data analysis dashboard developed to make basic data exploration, visualization, and machine learning easier for users. The application allows users to upload CSV or Excel datasets, preview the data, generate descriptive statistics, analyze variables, create visualizations, and apply simple machine learning models such as Linear Regression, Logistic Regression, and K-Means Clustering. It also provides evaluation outputs such as R², accuracy, confusion matrix, and clustering inertia, along with a clean user interface and dark/light mode support.

## Features

- Upload CSV or Excel datasets
- Preview uploaded datasets in a responsive table
- Generate descriptive statistics for numerical and categorical variables
- Create basic visualizations for single and multiple variables
- Perform variable-wise analysis
- Apply Linear Regression, Logistic Regression, and K-Means Clustering
- Display model evaluation results and predictions
- Dark and light mode dashboard interface

## AI-Assisted Development

This project was developed using AI-assisted tools, mainly Lovable and Cursor AI. Lovable was used to generate the initial frontend application from prompts, while Cursor AI was used to debug errors, refine UI components, and improve the functionality of statistics, charts, and machine learning models.

## Project Outcome

The final outcome is a functional frontend web application that supports data exploration, statistical summaries, visual analytics, and basic machine learning in an interactive dashboard environment.
